# Estado e evolução do Emissor

Implementados: servidor local, interface responsiva, quatro filtros opcionais independentes, limpeza de filtros, paginação, estados de carregamento/erro/vazio, consulta conjunta com metadados, recursos locais e API JSON documentada.

O acervo real permanece vazio. A base fictícia demonstra os recursos existentes e não representa provas reais. O servidor deve ser iniciado localmente para usar a interface.

Evoluções possíveis: índice para acelerar contagens, seleção de base pela interface e hospedagem autenticada. A renderização de fórmulas e formatos complexos exige contrato específico antes de implementação. Não há atualização jurídica automática nem revisão obrigatória; a situação cadastrada é apresentada ao usuário.

Implementada a área Adicionar material, compartilhando a interface com a consulta e delegando criação/anexação ao Captador. Próxima integração: processamento real pelo Digitalizador, ainda não disponível.

Registro de provas implementado com filtros de protocolo, dados da aplicação e estados. Encaminhamento protegido exige prova e gabarito; análises podem ser registradas manualmente com relatório. O Digitalizador ainda não executa os pacotes.
